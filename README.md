# Python Fundamentals Portfolio

This repository contains basic Python projects covering core fundamental concepts.

## Projects Included:
1. **Introduction Card**: Takes user input to print a formatted business/id card.
2. **Arithmetic Calculator**: Performs basic math operations (+, -, *, /, %, //, **) with zero division protection.
3. **Unit & Currency Converter**: Converts temperature, distance, and currency units with memory address tracking using id().
4. **Interest & Age Calculator**: Computes Simple/Compound Interest and calculates age based on birth year.
